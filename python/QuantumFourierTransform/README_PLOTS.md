# QFT Benchmark Comparison Plots

This directory contains scripts and generated plots comparing QFT performance between **LogosQ (Rust)**, **PennyLane (Python)**, and **Qiskit (Python)**.

## Generated Plots

The plotting script (`plot_qft_comparison.py`) generates three comparison plots:

1. **Execution Time Comparison** (`qft_execution_time_comparison.png`)
   - Linear and log scale views
   - Error bars showing standard deviation
   - Direct comparison of execution times

2. **Memory Usage Comparison** (`qft_memory_comparison.png`)
   - Memory consumption across different qubit counts
   - Shows memory efficiency of each library

3. **Speedup Comparison** (`qft_speedup_comparison.png`)
   - Shows speedup ratios compared to LogosQ (baseline)
   - Ratio > 1 means LogosQ is faster
   - Ratio < 1 means the other library is faster
   - Compares PennyLane and Qiskit against LogosQ

## Usage

### Generate Comparison Plots

```bash
cd /app/python/QuantumFourierTransform
python3 plot_qft_comparison.py
```

### Prerequisites

You need benchmark result files from the libraries you want to compare:

- **LogosQ results**: `/app/rust/qft_benchmark_results.json`
  - Generated by running: `cd /app/rust/QuantumFourierTransform && cargo run --example qft_benchmark_simple`

- **PennyLane results**: `/app/python/qft_benchmark_results.json`
  - Generated by running: `cd /app/python/QuantumFourierTransform && python3 pennylane_qft_benchmark.py`

- **Qiskit results**: `/app/python/qiskit_qft_benchmark_results.json`
  - Generated by running: `cd /app/python/QuantumFourierTransform && python3 qiskit_benchmark.py | grep QFT`
  - The script automatically saves results to the file

### Running Both Benchmarks

To generate complete comparison plots:

```bash
# 1. Run LogosQ benchmark (Rust)
cd /app/rust/QuantumFourierTransform
cargo run --example qft_benchmark_simple
# Select option 1-4 for benchmark range

# 2. Run PennyLane benchmark (Python)
cd /app/python/QuantumFourierTransform
python3 pennylane_qft_benchmark.py
# Select option 1-4 for benchmark range

# 3. Run Qiskit benchmark (Python)
cd /app/python/QuantumFourierTransform
python3 qiskit_benchmark.py > /tmp/qiskit_output.json 2>&1

# 4. Generate comparison plots
cd /app/python/QuantumFourierTransform
python3 plot_qft_comparison.py
```

**Note**: The plotting script will work with any combination of available results. You don't need all three libraries - it will plot whichever results are available.

## Output

Plots are saved to `/app/python/QuantumFourierTransform/`:
- `qft_execution_time_comparison.png` - Execution time comparison (linear & log scale)
- `qft_memory_comparison.png` - Memory usage comparison
- `qft_speedup_comparison.png` - Speedup ratios vs LogosQ (baseline)

All plots are saved at 300 DPI for publication quality.

## Library Colors and Markers

- **LogosQ (Rust)**: Blue circles (●) - `#2E86AB`
- **PennyLane (Python)**: Purple squares (■) - `#A23B72`
- **Qiskit (Python)**: Orange triangles (▲) - `#F18F01`

## Notes

- **Flexible comparison**: The script works with any combination of available libraries
  - If only LogosQ results exist, it will show LogosQ only
  - If multiple libraries are available, it will show all comparisons
  - Missing libraries are handled gracefully (no errors)
- **Error bars**: Shown when standard deviation data is available (LogosQ and PennyLane provide this)
- **Scales**: Log scale is used automatically for execution time when values span large ranges
- **Baseline**: LogosQ is used as the baseline for speedup comparisons
- **Summary statistics**: The script prints a summary table showing comparisons at common qubit counts
