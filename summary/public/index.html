Note: This comparison is based on actual test implementations.
  • PennyLane: Uses built-in PSR gradient system (confirmed bugs documented in BUG_SUMMARY.md). Focuses on quantum machine learning and hybrid quantum-classical computations.
  • Qiskit: Uses built-in PSR gradient system (may have similar issues). Comprehensive suite with IBM hardware integration.
  • LogosQ: Uses built-in PSR implementation (tested successfully). Type-safe Rust implementation with compile-time checks.
  • Yao.jl: Has built-in gradient computation via: (1) Classical Backpropagation using autodiff(:BP), (2) Quantum Circuit Differentiation using QDiff block, and (3) Julia's automatic differentiation via adjoint operator (expect'). The test uses manual PSR implementation only for direct comparison with other libraries' PSR implementations. Yao.jl emphasizes extensibility, performance, and algorithm design (Julia-based, smaller user base ~3.7%).
